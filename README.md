Project Name

QuickPay – Mobile Money Transfer App

Project Scope

QuickPay is a mobile payment app UI design focused on making digital money transfers simple and convenient. It provides an easy-to-use interface for selecting recipients, entering payment details and confirming transactions.

Project Objectives

- Design a user-friendly payment interface.
- Simplify the money transfer process.
- Provide clear transaction details.
- Create a smooth payment experience.

Project Screens

1. Home / Dashboard
2. Select Recipient & Send Money
3. Confirm Transfer
4. Money Transfer Success

Tools Used

- Figma

Key Features

- Available Balance
- Recent Transactions
- Recipient Selection
- Money Transfer
- Payment Confirmation
- Transaction Success Message
